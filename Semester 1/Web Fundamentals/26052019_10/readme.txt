TUTORIAL 10: FORMS, CSS STATES & INTERACTIVE APPOINTMENT SCHEDULING
========================================================================

STUDENT INFORMATION:
- Module: WEB1201 Web Fundamentals
- Date: August 2026

PROJECT OVERVIEW:
This project implements an interactive parent-staff appointment 
scheduling system for a school environment. It demonstrates clean 
separation of concerns between structural HTML, visual CSS state 
management, and interactive JavaScript logic.

TEST ENVIRONMENT:
- Primary Browser Tested: Google Chrome / Mozilla Firefox
- Dependencies: None (Pure Vanilla HTML5, CSS3, and JavaScript ES6)

HOW TO RUN:
1. Extract the project archive (Surname_Tutorial10_Appointment.zip).
2. Open 'index.html' directly in any modern web browser.
3. No local server (e.g., XAMPP/Live Server) is required as the page 
   runs purely on client-side web standards.

TASK COMPLIANCE & TEST CONFIRMATION:
- Task 1 (Appointment Form Validation): Verified that submitting an 
  invalid email or a past date blocks submission, displays red border 
  styling, and renders a dynamic inline red error message.
- Task 2 (Time-Slot Picker): Verified that available slots turn blue 
  when selected, clear previous selections, ignore booked gray slots, 
  and render a confirmation text banner.
- Task 3 (Staff Directory Filtering): Verified that typing "Math" 
  into the search box filters visible cards in real time, hiding 
  non-matching departments without destroying data arrays.
- Task 4 (Confirmation Composer): Verified that selecting the 
  "Academic Concerns" dropdown option populates the confirmation text 
  area with the required specific learning-plan text.
- Task 5 (Progress Tracking): Verified that advancing through steps 
  recomputes the derived percentage state, updating the progress bar 
  width to 33%, 66%, and 100% alongside the textual step label.
