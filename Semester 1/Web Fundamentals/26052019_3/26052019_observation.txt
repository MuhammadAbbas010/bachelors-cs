TASK 1: Border & Box Model Observations

Observations & Discussion:
- Adding a border to a block element (like <h1>) causes the border to span 100% of the viewport width.
- Adding padding creates empty breathing space between the element's inner text content and its outer border line.

QUESTIONS 2: Resolution & Image Types

1. What is resolution and how is it measured?
   Resolution is the level of detail held in an image, measured in PPI (Pixels Per Inch) for screen displays or DPI (Dots Per Inch) for print.

2. Difference between screen and printed resolution:
   Screen resolution requires lower pixel density (typically 72–96 PPI) for fast web loading, whereas print media requires high density (300+ DPI) for sharp ink output.

3. Colour formation on screens vs. printed media:
   - Screen (Additive / RGB): Uses Red, Green, and Blue light combined to produce white light.
   - Printed Media (Subtractive / CMYK): Uses Cyan, Magenta, Yellow, and Key (Black) ink to absorb light; combining all produces black. Spot/Pantone colors use pre-mixed custom inks.

4. Typical web image resolution:
   72 PPI to 96 PPI.

5. Reason for this resolution:
   Computer displays cannot physically render higher pixel densities than their hardware specs allow, so higher PPIs only increase file size and slow down page load times without visual improvement.

6. Difference between vector and raster images:
   - Raster: Made of a fixed grid of colored pixels. Scales down well, but loses quality (becomes pixelated) when scaled up.
   - Vector: Made of mathematical formulas (lines, curves, anchor points). Scales infinitely without quality loss.

7. Examples of 4 file formats each:
   - Raster Formats: .png, .jpg / .jpeg, .gif, .webp
   - Vector Formats: .svg, .eps, .ai, .pdf

8. Usage examples for each:
   - Raster: Photographs, complex shaded illustrations, web graphics.
   - Vector: Logos, typography, simple icons, graphic diagrams.

9. Usage on the web:
   Use vectors (.svg) for scalable UI elements like logos, buttons, and icons to keep crisp display across all device screens. Use rasters (.jpg/.png) for complex photographic assets where mathematical paths cannot represent color gradients efficiently.



QUESTIONS 3: Resolution & Image Size

1. Relationship between resolution and number of pixels:
   Total pixel count equals width in pixels multiplied by height in pixels. Higher resolution in a fixed physical area increases the total pixel count.

2. Meaning of a large or small raster image:
   - Large raster: Contains high pixel dimensions (e.g., 4000x3000px), producing crisp detail and large file sizes.
   - Small raster: Contains low pixel dimensions (e.g., 50x50px), producing tiny file sizes but blurring if enlarged.

3. How to specify raster image size:
   Set image dimensions using HTML `width`/`height` attributes or CSS `width`/`height` properties in pixels.

4. Can you specify vector image size?
   Yes, vector sizes are specified via CSS width/height or the SVG `viewBox` and `width`/`height` XML attributes without affecting pixel grid density.



TASK 4 & 5: Background Image Testing & Observations

Background Testing Summary:
- Smaller backgrounds (10x10, 10x20) tile across the entire viewport by default like wallpaper.
- Applying `background-size: 100%` stretches a tiny raster background across the screen, causing severe pixelation.
- Using SVG vector backgrounds allows crisp scaling across all screen sizes without tiling distortion.
- Applying background images to specific elements (like <h1>) with `background-repeat: no-repeat` and `background-position: center` creates clean hero banners and custom icons.



QUESTIONS 4: Background Image Decisions

1. Should background image be raster or vector?
   Vector (.svg) is preferred for geometric patterns, gradients, and logos. Raster (.jpg) is better for photos.

2. Circumstances for using either:
   Use vector when infinite scalability and small file sizes are required. Use raster when background requires complex photorealistic detail.

3. Optimal pixel dimension for background images:
   For seamless repeating patterns, small tiles (e.g., 20x20px to 100x100px). For full-screen hero banners, 1920x1080px compressed high-quality raster or scalable SVG.

4. Effect of including/excluding background-size:
   - Excluding `background-size`: Image renders at intrinsic pixel size and tiles across the element.
   - Including `background-size: cover/contain/100%`: Forces image to scale to fit or fill the element container bounds.
